# Instalación local

No hay dependencias que instalar. Abrí `index.html` en un navegador moderno. Para una vista más parecida a producción podés servir la carpeta con cualquier servidor estático local, pero no es un requisito de ejecución.

El formulario funciona en modo demostración sin enviar datos. Para recibir solicitudes hay que configurar un proveedor de formularios estáticos y completar `formularioEndpoint` en `js/configuracion.js`, sin incluir claves privadas.

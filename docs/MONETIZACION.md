# Monetización y comisiones

La web presenta un modelo posible, pero no ejecuta pagos, reservas, suscripciones ni liquidaciones. Las contrataciones deben atribuirse mediante enlaces de referencia o acuerdos verificables con cada profesional.

Un acuerdo comercial debería definir porcentaje o importe, hecho que genera comisión, cancelaciones, reembolsos, liquidación, impuestos y canales de reclamo. No se solicitan tarjetas ni datos bancarios en AjedrezTotal.

# Publicación

El proyecto puede desplegarse en un hosting estático. GitHub Pages debe revisarse antes de un lanzamiento comercial: sus límites y términos oficiales pueden restringir sitios cuyo propósito principal sea facilitar transacciones comerciales. No se afirma aquí que el modelo de AjedrezTotal cumpla automáticamente.

Si el modelo de comisiones no encaja, mantené el repositorio en GitHub y usá un proveedor de hosting estático compatible con ese uso. Antes de definir un dominio, completá `AjedrezConfig.dominio`, canonical, sitemap y redes sociales; no se inventan valores.

Referencias oficiales: [límites de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits), [términos adicionales](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features) y [qué es GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
